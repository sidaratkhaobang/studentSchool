# Module หลัก

## Authentication

| หน้า | หน้าที่ |
| --- | --- |
| `/login` | เข้าสู่ระบบด้วย username/password และ redirect ตาม role |
| `/register` | สมัครบัญชีนักเรียน ได้สถานะ `pending` รอ Admin อนุมัติ |

API ใช้ Laravel Sanctum และตรวจสิทธิ์ `admin`, `teacher`, `student` แยกตามกลุ่ม route

## Admin

| หน้า | หน้าที่ |
| --- | --- |
| `/admin/dashboard` | สรุปข้อมูลระบบ |
| `/admin/teachers` | เพิ่ม แก้ไข ดูรายการ และลบข้อมูลอาจารย์ตามข้อกำหนด |
| `/admin/subjects` | จัดการรายวิชาและสถานะเปิดใช้งาน |
| `/admin/assignments` | ผูกอาจารย์กับรายวิชาและกำหนดอาจารย์หลัก |
| `/admin/students` | ดูข้อมูลนักเรียน กรองสถานะ และ approve/reject บัญชีนักเรียน |

## Teacher

| หน้า | หน้าที่ |
| --- | --- |
| `/teacher/dashboard` | สรุปจำนวนวิชาที่รับผิดชอบ ชั้นเรียน นักเรียนในความดูแล และตารางที่รออนุมัติ |
| `/teacher/enrollments` | ดูรายละเอียดตาราง จันทร์-ศุกร์ และอนุมัติหรือปฏิเสธพร้อมเหตุผล |
| `/teacher/subjects` | จัดการเนื้อหาการสอนและเอกสารแนบของรายวิชาที่รับผิดชอบ |

Teacher ดูและตัดสินตารางได้เฉพาะนักเรียนที่มี `advisor_teacher_id` ตรงกับตนเอง ข้อมูลชั้นเรียนปัจจุบันใช้ `students.grade_level` ยังไม่มีตารางห้องเรียนแยก

## Student

| หน้า | หน้าที่ |
| --- | --- |
| `/student/dashboard` | ดูตารางรายสัปดาห์ ชั่วโมงรวม ข้อมูลชั้นเรียน และอาจารย์ที่ปรึกษา |
| `/student/profile` | ดู/แก้ไขข้อมูลส่วนตัวและเปลี่ยนรหัสผ่าน |
| `/student/enrollment` | สร้างตาราง เพิ่ม/ลบวิชา ส่งอนุมัติ และแก้ไขตารางที่ถูกปฏิเสธ |

นักเรียนดาวน์โหลดเอกสารประกอบรายวิชาจากตารางเรียนได้เมื่อมีไฟล์แนบ

## งานที่ยังเหลือ

ประวัติตารางทุกสัปดาห์แบบละเอียด การตรวจเวลาเรียนซ้อน ระบบแจ้งเตือน และ entity ห้องเรียนจริง ยังเป็นงาน phase ถัดไป ดู [Project Scope](ProjectScope.md)
